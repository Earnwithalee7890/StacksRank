# Security Policy

## Supported Versions

We currently support the following versions of StacksRank with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of StacksRank seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

**Please do not report security vulnerabilities via public GitHub issues.**

Instead, please send an email to [security@stacksrank.com](mailto:security@stacksrank.com).

### What to Expect

* You will receive an acknowledgment of your report within 48 hours.
* We will send a follow-up once we have analyzed the report, usually within 7 days.
* If a fix is required, we will work with you to coordinate a disclosure date once the fix is ready.

### Disclosure Policy

* We follow a 90-day disclosure policy for critical vulnerabilities.
* We ask that you do not disclose the vulnerability until we have had a chance to fix it and release an update.
