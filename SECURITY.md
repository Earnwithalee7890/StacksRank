# 🛡️ Security Policy

## Supported Versions

We only provide security updates for the current main branch and latest production releases.

| Version | Supported |
| --- | --- |
| 1.3.x | ✅ Yes |
| 1.2.x | ❌ No |
| < 1.1.0 | ❌ No |

## Reporting a Vulnerability

**Do not open a GitHub issue for security vulnerabilities.**

If you discover a security risk, please report it privately:

1.  **Email**: Contact us at [security@stacksrank.org](mailto:security@stacksrank.org).
2.  **Details**: Provide a full description of the vulnerability, including steps to reproduce.
3.  **Encrypted Message**: If necessary, we can provide a PGP key for sensitive communication.

We aim to respond within 48 hours and resolve critical issues within 1 week of confirmation.

## 🔒 Best Practices

- Always verify contract addresses before interacting.
- Use a hardware wallet for high-value transactions.
- Never share your seed phrase or private keys.
