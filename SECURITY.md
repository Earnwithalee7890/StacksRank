# Security Policy

## Supported Versions

The following versions of StacksRank are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :x:                |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

We take the security of our users and their funds very seriously. If you find a security vulnerability, please do NOT open a public issue. Instead, please report it privately.

Please send an email to security@stacksrank.org with a detailed description of the vulnerability and steps to reproduce it.

### What to expect

- We will acknowledge receipt of your report within 48 hours.
- We will provide a timeline for fixing the issue.
- We will keep you updated on the progress of the fix.
- We will credit you for the discovery in our changelog (unless you wish to remain anonymous).

### Out of Scope

- Issues related to third-party wallet providers (Leather, Xverse, etc.).
- Issues related to the Stacks network itself.
- Theoretical vulnerabilities without a clear proof-of-concept.
