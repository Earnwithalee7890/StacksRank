# StacksRank Project Roadmap 🚀

This roadmap outlines the planned growth for StacksRank as we build the premier reputation and DeFi hub for the Stacks ecosystem.

## Phase 1: Foundation (Q1 2026 - Current) ✅
- [x] Initial mainnet deployment of core contracts (Reputation, Swap, Vault).
- [x] Builder Tools and Daily Check-in system.
- [x] Vanilla JS / HTML5 Responsive Frontend.
- [x] Direct Leather Provider Wallet Integration.
- [x] Launch of `stacksrank-sdk` npm package.

## Phase 2: Ecosystem Integration (Feb 2026) 🏗️
- [ ] **SIP-010 Token Support Expansion**: Add more community tokens to the swap engine.
- [ ] **Xverse Wallet Support**: Further testing and optimization for Xverse and Asigna.
- [ ] **Contract Verification**: Automate contract source verification on HIRO Explorer for new tools.
- [ ] **Community Rewards**: Implement the `stx-distributor` claim limits based on reputation score.

## Phase 3: Advanced DeFi Features (Q2 2026) 🛡️
- [ ] **ClarityVault v2**: Multi-sig dashboard with approval history.
- [ ] **Reputation-based Tiers**: Unlock lower swap fees by maintaining a 30-day check-in streak.
- [ ] **GraphQL Indexing**: Move from REST to a GraphQL subgraph for faster leaderboard updates.
- [ ] **Mobile App**: PWA (Progressive Web App) support for checking streaks on the go.

## Phase 4: Decentralization (Late 2026) 🌐
- [ ] **DAO Governance**: Hand over fee distribution decisions to the top 100 on the leaderboard.
- [ ] **Developer Portal**: Automated documentation generation for the SDK.
- [ ] **Open Analytics**: Real-time TVL and volume charts using Hiro Data.
